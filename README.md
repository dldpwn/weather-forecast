# 🥗 NutriDay | 나만의 영양 관리 웹앱

#1. 프로젝트 소개

 NutriDay는 사용자의 신체 정보와 생활 습관을 바탕으로 하루 에너지 필요량을 계산하고, 개인에게 적합한 식단과 영양 섭취 현황을 관리할 수 있도록 제작한 웹 애플리케이션이다. 기초대사량(BMR)과 하루 에너지 필요량(EER)을 계산하여 개인별 영양 관리의 기준을 제공하며, 식품영양성분 데이터베이스를 활용해 음식에 포함된 영양소를 분석할 수 있도록 구성하였다. 식단 계획부터 실제 식사 기록, 영양소 분석까지 하나의 웹앱에서 관리할 수 있다는 점이 특징이다.

#2. 주요 기능 설명

 1) 기초대사량 및 하루 에너지 필요량 계산

  - 사용자의 나이, 성별, 키, 몸무게 등의 신체 정보를 입력한다.
  - 연령과 성별에 적합한 계산식을 적용하여 기초대사량(BMR)을 계산한다.
  - 사용자의 신체 활동 수준을 반영하여 하루 에너지 필요량(EER)을 추정한다.
  - 계산 결과를 개인별 식단 구성과 영양 관리의 기준으로 활용한다.

 2) 맞춤형 식단 플래너

  - 계산된 하루 에너지 필요량을 바탕으로 개인 맞춤 식단을 구성한다.
  - 아침, 점심, 저녁, 간식으로 구분된 한 달 단위의 식단을 제공한다.
  - 날짜별 식단을 다시 생성하여 다양한 식단을 확인할 수 있다.
  - 식단에 포함된 음식의 영양 정보를 확인할 수 있다.

 3) 식사 기록 및 영양 분석

  - 아침, 점심, 저녁, 간식으로 구분하여 실제 섭취한 음식을 기록한다.
  - 음식 이름과 섭취량, 단위를 입력하고 기록을 저장할 수 있다.
  - 식품영양성분 데이터베이스를 활용하여 섭취한 음식의 영양소 함량을 계산한다.
  - 하루 총열량과 탄수화물, 단백질, 지방의 섭취량을 확인할 수 있다.
  - 칼슘, 철, 나트륨, 칼륨 등의 무기질과 비타민 섭취량을 확인할 수 있다.
  - 영양소별 섭취 현황을 표와 그래프로 시각화한다.

#3. 사용법

 1) 기초대사량 및 하루 에너지 필요량 계산

  - 첫 번째 페이지에서 나이, 성별, 키, 몸무게 등의 신체 정보를 입력한다.
  - 평소 신체 활동 수준을 선택한다.
  - 계산 버튼을 눌러 기초대사량과 하루 에너지 필요량을 확인한다.

 2) 맞춤형 식단 확인

  - 식단 플래너 페이지로 이동한다.
  - 개인의 하루 에너지 필요량을 바탕으로 구성된 식단을 확인한다.
  - 날짜별 식단을 확인하고, 필요한 경우 다시 생성하여 다른 식단을 확인한다.

 3) 식사 기록

  - 식사 기록 페이지로 이동한다.
  - 기록할 날짜와 식사 항목(아침, 점심, 저녁, 간식)을 선택한다.
  - 음식 이름과 섭취량, 단위를 입력한 후 기록을 저장한다.

 4) 영양 분석 결과 확인

  - 저장된 식사 기록을 바탕으로 하루 총열량과 영양소 섭취량을 확인한다.
  - 탄수화물, 단백질, 지방의 에너지 기여율과 무기질 섭취량을 그래프로 확인한다.
  - 최근 7일간의 영양소 섭취 추이를 확인하여 식사 기록에 따른 영양 상태의 변화를 살펴본다.

#4. 실행 방법

 1. 인터넷에 연결된 환경에서 웹 브라우저를 실행한다.
 2. NutriDay 웹앱이 배포된 Streamlit Cloud 주소에 접속한다.
 3. 회원가입을 진행한 후 가입한 계정으로 로그인한다.
 4. 로그인 후 메인 페이지에서 원하는 기능을 선택하여 이용한다.
